# Quickstart: Smart Inbox Organizer

## Prerequisites

- Node.js 20
- Gmail account with permission to read, label, archive, and delete

## Run (TUI MVP)

1. Configure Gmail credentials for local use.
2. Launch the TUI application.
3. Authenticate with Gmail and load the inbox.
4. Use filters or a natural-language query to narrow results.
5. Select emails and confirm actions (label/archive/delete).

## Saved Queries Workflow

1. Run a query and save it with optional action.
2. On next session start, re-run saved queries against new emails.
3. Confirm actions before applying them.

## Notes

- Email content is not persisted after the session ends.
- This MVP is TUI-only; a local web app is planned as a fast follow.
