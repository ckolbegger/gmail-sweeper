# Gmail Sweep

Gmail Sweep is a TUI tool for managing your inbox.

## Keybindings

- `Up/Down Arrows`: Navigate emails or scroll email content
- `Enter`: Open email details
- `Esc`: Close detail view or exit
- `f`: Filter emails using natural language (powered by AI)
- `s`: Generate and view an AI summary of the selected email (toggles view)
- `Tab`: Cycle through links in an email
- `Return`: Open focused link in browser
- `c`: Copy focused link to clipboard
